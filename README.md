## Overview

**Yalla Car** is a car rental marketplace for Jordan. Jordanian rental companies create accounts and list their cars, while customers (locals, and travellers booking from abroad before they arrive) search, compare, and book.

This repository contains the full **UI/UX design**: style guide, wireframe, and high-fidelity mockups for all 11 pages in Arabic (RTL), plus an English version of the home page.

## Users

| User | Role |
|---|---|
| **Customer** | Searches for a car, books it, and tracks bookings |
| **Rental company** | Lists cars, manages bookings, and tracks earnings |
| **Admin** | Approves new companies and monitors the platform |

## Pages

| Side | Pages |
|---|---|
| **Customer** | Home, Search Results, Car Details, Booking & Payment, Login / Register, My Bookings |
| **Company dashboard** | Add Car, Manage Cars, Incoming Bookings, Earnings & Stats |
| **Admin** | Company Approvals |

## Open in Figma

1. Create a new file on [Figma](https://www.figma.com/design/0cpKuKvib0wKCZVBLRdOpr/master-beas?node-id=2-222&t=P0L0tjuuCchluuE3-1).
2. Drag the SVG files from `design/` onto the canvas (each file becomes a frame).
3. Make sure the **Cairo** font is available (free on Google Fonts).

> Note: SVG import keeps shapes and text. Auto Layout, Components, and Prototype links need to be added in Figma.
